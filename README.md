# Firstmob · 姚永寿

Minecraft **1.21.1 Fabric** 模组：新增生物「姚永寿」。
它长着僵尸的样子，行为却来自羊驼——会寻路、会走近、会吐口水；听到玩家弄出动静会主动找上门，吵得太厉害还会放监守者声波。

## 支持的版本

版本范围与 `src/main/resources/fabric.mod.json` 的 `depends` 保持一致：

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| Minecraft | **1.21.1**（`~1.21.1`） | 只在该版本开发与验证，1.21.2+ 不保证可用 |
| Fabric Loader | **≥ 0.20.1** | 低于此版本会被拒绝加载 |
| Fabric API | `*`（开发/测试用 `0.116.17+1.21.1`） | 必须安装，否则启动失败 |
| Java | **≥ 21** | 编译与运行都按 21 配置 |
| 安装位置 | 客户端 + 服务端 | `environment: "*"`，联机时两端都要放 |

升级游戏版本前要重新核对 `LlamaEntity`、`ProjectileAttackGoal`、`ServerPlayerInteractionManager` 等原版签名，见 [接口文档](docs/API.md)。

## 快速开始

```mcfunction
/summon firstmob:yao_yongshou ~ ~ ~
/give @s firstmob:yao_yongshou_spawn_egg
```

刷怪蛋也在创造模式「刷怪蛋」页签里。装好模组后把它放进 `mods/`，同时安装上表的 Fabric Loader 与 Fabric API。

## 玩法速览

> 血量阈值按最大生命（100 点）的比例计算。下面按 **非 Boss / Boss** 分开，各自从高血量往低血量介绍；与血量无关的内容放在最后。

### 非 Boss（血量 ≥ 80%）

#### 100%：刚生成
- **100 点生命**、护甲 5、护甲韧性 0、体型 1 倍，没有 Boss 血条，就是普通生物。

#### 100% → 80%：普通形态
- **空闲游走**：没有目标时跟着最近的玩家，**始终 ≥16 格**：20 格内盯着你看，16~32 格站定不动，>32 格靠近，<16 格后退；**>48 格**传送到你**侧前方 18~22 格**（不会出现在正前方）。
- **听觉 / 愤怒**：20 格内玩家弄出真噪音会积累愤怒——挖放、开关容器、吃喝、射箭等 **+12**；脚步、落地、受击 **+5**，且每类 5 秒最多一次。愤怒 **30** 进入警觉、开始吐口水；**100** 激怒、改放声波。冷静时听到声音只转头看声源 **40 tick**，不锁人。
- **攻击距离**：3 格内只近战（**15 点**）；3~20 格吐口水（**4 点** + 击退）；20 格以外先走近。近战与口水**和平难度同样生效**。
- **声波**：愤怒满（约 **9 次真噪音**）时，声波**替代**口水（3 格以外都放，最远 40 格），蓄力 34 tick，**10 点穿甲** + 击退，每 8 秒一发；目标离开 40 格、死亡或愤怒回落到 90 以下才停。
- **潜行与遮挡**：潜行脚步不算；**羊毛墙**会挡住声音。
- **挨打反击**：每次被打最多还手 **3 次**，打完收手；再打一次重新计数。
- **放弃追击**：目标跑出 **25 格**就放弃（声波模式除外）。
- **速度**：游走速度 III，追击速度 II，进入近战距离收回。

### Boss（血量 < 80%）

#### < 80%：变身
- 体型 **2 倍**、护甲 **20**、护甲韧性 0，顶部出现「姚永寿」红色血条（随伤害下降、死亡收起）。
- 获得**永久**速度 I、力量 I、**抗性提升 I**；没有目标时仍按普通形态的空闲游走规则行动。
- 变身瞬间爆出一团橙 → 紫尘团。
- **进入 Boss 立刻激怒**：当前/最近玩家愤怒直接拉满，马上改放声波，不需要先攒噪音。
- 听觉、口水、近战、反击沿用上面的规则。

#### < 60%：死咬（锁定）
- 不再按愤怒/距离脱战，**始终锁定玩家**：优先咬最近一次打它的玩家，其次是最近的存活玩家。
- 距离分工：**5 格内**只近战（15 点）；**5~16 格**吐口水；**17~32 格**站定蓄力放声波（10 点穿甲）；**超过 32 格到 40 格**边追边放声波；**>40 格**只追不打。
- 声波蓄力一旦开始就先打完这一发：蓄力期间不切近战/口水，即使你贴到脸上或跑出 40 格也照常结算。
- 追击时挂速度 II；锁定期间不执行「好奇」「警觉口水」和「25 格放弃」。
- 锁定即**狂暴**：血条变紫、标题加「（狂暴）」，只改表现，不改攻速与伤害。
- 目标死亡时改锁最近的存活玩家；被别的玩家打会先咬那名玩家。
- 解锁条件：自己**回满血** **且** 30 秒内没被玩家打中，两条同时满足才放开目标。

#### < 20%：濒死
- 每次从 20% 以上掉到 20% 以下，获得附魔金苹果效果：**伤害吸收 III**、生命恢复 II（30 秒）、抗性提升与抗火（各 5 分钟）。
- 护甲改为 **10**、护甲韧性 **5**；回到 20% 以上立刻改回 20/0。
- 口水、声波蓄力与循环的冷却都缩短 **20%**。
- 触发瞬间爆出不死图腾粒子；回血到 20% 以上再掉下来会再触发一次。

#### 任意血量：持续规则
- **脱战回血**：玩家连续 **10 秒**没有造成伤害时，获得生命恢复 I，直到满血；再被玩家打中或回满后停止（普通形态也生效）。
- **退回普通**：解除锁定后（或从未锁定）连续 **30 秒没有目标**，退回普通形态（体型 1 倍、护甲 5、力量与抗性提升消失、血条收起）；血量仍 <80% 时，再被打或被激怒会立刻重新变身。锁定期间不会退回。

### 攻击距离速查

Boss 但还没到 60% 时，攻击距离与普通形态相同。

| 距离 | 非 Boss（≥80%） | Boss 锁定（<60%） |
| --- | --- | --- |
| 贴身 | ≤3 格：近战 15 点 | ≤5 格：近战 15 点 |
| 中距 | 3~20 格：口水 4 点 + 击退 | 5~16 格：口水 4 点 + 击退 |
| 远距 | >20 格：先走近；25 格放弃 | 17~32 格：站定声波 10 点穿甲 |
| 更远 | 声波模式例外，可追到 40 格 | >32~40 格：边追边放声波 |
| 超远 | — | >40 格：只追不打，速度 II |

**非 Boss 的远程手段只看愤怒档位**：警觉（约 3 次真噪音）吐口水；激怒（约 9 次）声波替代口水，最远 40 格。

### 与血量无关

| 机制 | 表现 |
| --- | --- |
| 外形 | 僵尸模型与贴图，待机双臂前伸；近战命中抬臂抡下 0.5 秒，不继承僵尸行为 |
| 同类 | 不互相索敌，口水也不伤害同类 |
| 幼年 / 繁殖 | 没有幼年形态，不能繁殖、喂食或驯服 |
| 常驻 | 不会因为玩家跑远被自然清除，只能打死或用指令移除 |
| 掉落经验 | 玩家击杀掉落 **500 点**经验 |
| 字幕 | 环境音、受伤、死亡、吐口水、蓄力、声波都有「姚永寿：…」专属字幕 |
| 粒子 | 有任意速度走路时脚下拖烟花；近战命中在目标脚下扬尘（变身 / 濒死粒子见上文） |

完整的判定条件、状态机与数值见 [行为规范](docs/SPEC.md)；接口与资源契约见 [接口文档](docs/API.md)。

## 构建

```powershell
$env:JAVA_HOME='D:\pcl\jdk-21'
$env:GRADLE_USER_HOME='D:\pcl\gradle_cache'
.\gradlew.bat build        # 产物 build/libs/firstmob-1.0.0.jar
.\gradlew.bat runClient    # 开发客户端，测试世界 run/saves/新的世界
```

国内网络所需镜像已写进仓库：阿里云 Maven（`build.gradle`）、BMCLAPI（`gradle.properties` 的 `loom_*`）、腾讯云 Gradle 发行包（`gradle/wrapper`）。
`gradle.properties` 里的 `org.gradle.java.home` 指向本机 JDK 21，换机器时按需修改。

## 已知限制

- 刷怪蛋是单面平面模型：侧视是一条线，掉落物转到背面看不到图案。
- 创造模式玩家免疫伤害：口水只击退；近战与声波不结算伤害，其中近战的动作与尘柱照常播放，声波只剩粒子与音效。
- 声波沿用原版 `minecraft:sonic_boom`（`scaling: always`），和平难度伤害归零。
- 听觉以监守者式振动为主，音效只补原版没有 GameEvent 的声音；潜行时音效补充关闭，羊毛挡声，振动按距离最多晚约 1 秒结算。
- 锁定后的「狂暴」只改血条表现，不改攻速与伤害。
- 只保留僵尸外观，交易、职业、脑 AI 一概不继承。
