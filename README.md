# Firstmob · 姚永寿

Minecraft **1.21.1 Fabric** 模组：新增生物「姚永寿」。
它长着僵尸的样子，行为却来自羊驼——会寻路、会走近、会吐口水；听到玩家弄出动静会主动找上门，吵得太厉害还会放监守者声波。

## 支持的版本

版本范围与 `src/main/resources/fabric.mod.json` 的 `depends` 保持一致：

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| Minecraft | **1.21.1**（`~1.21.1`） | 只在该版本开发与验证，1.21.2+ 不保证可用 |
| Fabric Loader | **≥ 0.20.1** | 低于此版本会被拒绝加载 |
| Fabric API | `*`（开发/测试用 `0.116.17+1.21.1`） | 必须安装，否则启动失败 |
| Java | **≥ 21** | 编译与运行都按 21 配置 |
| 安装位置 | 客户端 + 服务端 | `environment: "*"`，联机时两端都要放 |

升级游戏版本前要重新核对 `LlamaEntity`、`ProjectileAttackGoal`、`ServerPlayerInteractionManager` 等原版签名，见 [接口文档](docs/API.md)。

## 快速开始

```mcfunction
/summon firstmob:yao_yongshou ~ ~ ~
/give @s firstmob:yao_yongshou_spawn_egg
```

刷怪蛋也在创造模式「刷怪蛋」页签里。装好模组后把它放进 `mods/`，同时安装上表的 Fabric Loader 与 Fabric API。

## 玩法速览

### 基础

| 机制 | 表现 |
| --- | --- |
| 外形 | 僵尸模型与贴图，待机双臂前伸；近战命中会抬臂抡下（0.5 秒），不继承僵尸的任何行为 |
| 血量 | **100 点**生命；刚生成时护甲 0、体型 1 倍，就是普通生物 |
| 常驻 | 不会因为玩家跑远被自然清除，只能打死或用指令移除 |
| 掉落经验 | 玩家击杀掉落 **500 点**经验 |

### 血量阶段（单向推进）

| 血量 | 变化 |
| --- | --- |
| **< 80%** | 变 Boss：体型 2 倍、护甲 20（约减伤 80%）、顶部出现「姚永寿」红色血条（随伤害下降、死亡收起），并获得**永久**速度 I、力量 I；回血也不会退回普通形态 |
| **< 60%** | 死咬玩家：始终锁定，5 格内近战、5~20 格吐口水、20~40 格声波；被打也先咬打它的那名玩家 |
| 追击加速 | 锁定后跑出 **40 格**外获得速度 II，回到 **20 格**内恢复速度 I（20~40 格之间不变） |
| 解除锁定 | 自己回满血 **且** 30 秒内没被玩家打中，两条同时满足才放开目标 |
| **< 20%** | 每次从 20% 以上掉到 20% 以下：伤害吸收 IV、生命恢复 II（30 秒）、抗性提升、抗火（各 5 分钟） |
| 低血加速 | 血量 20% 以下：口水、声波蓄力与循环的冷却都缩短 20% |

### 战斗

| 机制 | 表现 |
| --- | --- |
| 听觉索敌 | 20 格内，玩家 5 秒内弄出 **3 次真噪音**（挖掘、放置、吃喝、游泳等）就会被锁定 |
| 走路/跳跃/受击 | 只记录、不触发，光跑不会把它叫过来 |
| 远程口水 | 4 点伤害 + 击退，和平难度同样生效；冷却 34 tick（约 1.7 秒） |
| 贴身近战 | 3 格内只近战（锁定模式 5 格）、不放任何远程；伤害 **15 点**（铁傀儡数值），命中把目标向上顶飞 |
| 挨打反击 | 普通模式每次被打最多还手 **3 次**，打完收手；再打一次重新计数 |
| 监守者声波 | 5 秒内真噪音 **≥ 9 次**升级：声波**替代**口水（3 格以外都放，最远 40 格），蓄力 34 tick，10 点穿甲伤害 + 击退，每 8 秒一发 |
| 声波停止 | 目标离开 40 格或死亡才停（被打断除外）；期间不因安静停火 |
| 放弃追击 | 非 Boss 模式目标跑出 25 格即放弃；Boss 锁定后不放弃 |

### 攻击距离速查

| 距离 | 非 Boss（未进入 60% 锁定） | Boss（血量 < 60%，锁定） |
| --- | --- | --- |
| 近身（≤ 3 格 / Boss ≤ 5 格） | 近战 15 点 | 近战 15 点 |
| 中距（3~20 格 / Boss 5~20 格） | 口水 4 点 + 击退 | 口水 4 点 + 击退 |
| 20~40 格 | 口水（超过 20 格会先走近；除非已攒满 9 次噪音改放声波） | 声波 10 点穿甲 |
| > 40 格 | 口水（先走近，永远不会自己改放声波） | 只追不打，挂速度 II |
| 放弃追击 | 25 格以外放弃 | 不放弃，一直追 |

**非 Boss 的远程手段只看噪音，不看距离**：5 秒内真噪音 ≥ 9 次 → 声波**替代**口水（3 格以外都放声波，到 40 格才退出）；没到 9 次 → 无论多远都只吐口水。

### 其他

| 机制 | 表现 |
| --- | --- |
| 同类 | 不互相索敌，口水也不伤害同类 |
| 幼年/繁殖 | 没有幼年形态，不能繁殖、喂食或驯服 |
| 字幕 | 环境音、受伤、死亡、吐口水、蓄力、声波都有「姚永寿：…」专属字幕 |

完整的判定条件、状态机与数值见 [行为规范](docs/SPEC.md)；接口与资源契约见 [接口文档](docs/API.md)。

## 构建

```powershell
$env:JAVA_HOME='D:\pcl\jdk-21'
$env:GRADLE_USER_HOME='D:\pcl\gradle_cache'
.\gradlew.bat build        # 产物 build/libs/firstmob-1.0.0.jar
.\gradlew.bat runClient    # 开发客户端，测试世界 run/saves/新的世界
```

国内网络所需镜像已写进仓库：阿里云 Maven（`build.gradle`）、BMCLAPI（`gradle.properties` 的 `loom_*`）、腾讯云 Gradle 发行包（`gradle/wrapper`）。
`gradle.properties` 里的 `org.gradle.java.home` 指向本机 JDK 21，换机器时按需修改。

## 已知限制

- 刷怪蛋是单面平面模型：侧视是一条线，掉落物转到背面看不到图案。
- 创造模式玩家免疫伤害：口水只击退；声波连击退也不结算，只剩粒子与音效。
- 声波沿用原版 `minecraft:sonic_boom`（`scaling: always`），和平难度伤害归零。
- 方块声音按「挖掘 / 交互动作」计数，不按真实音效事件；交互失败、开箱子等也会计一次。
- 只保留僵尸外观，交易、职业、脑 AI 一概不继承。
